## Extra parts library

Wire Channel Designer includes 1,369 extra parts converted from these Fritzing part libraries. Each part's outline size and pin positions come from its PCB-view drawing. Heights are estimates, because Fritzing files don't include them.

| Library | Source | Licence |
|---|---|---|
| Fritzing core and contrib parts | https://github.com/fritzing/fritzing-parts | [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) |
| SparkFun Fritzing parts | https://github.com/sparkfun/Fritzing_Parts | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| Adafruit Fritzing library | https://github.com/adafruit/Fritzing-Library | [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) |

The converted part data (the `FZ_PARTS` list in `index.html`) is a derivative of these libraries. It is shared under the same CC BY-SA licence, and you are free to reuse it under those terms. The rest of the tool keeps its own licence (see LICENSE).

Every converted part is tagged with the library it came from. Its info card shows "From: Fritzing / SparkFun / Adafruit".
